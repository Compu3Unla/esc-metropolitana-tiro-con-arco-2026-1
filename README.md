# Proyecto de rediseño para EMTA
EMTA es la “Escuela Metropolitana de Tiro con Arco” que dicta clases de tiro de salón orientadas principalmente al Tiro Olimpico.
Está ubicada en el barrio Villa Mitre y está dirigida a todas las edades y niveles.
Su página web actual cuenta con problemas de diseño, de usabilidad y de diagramación de contenidos, y es por eso que la elegimos para el proyecto.

### ¿Qué proponemos?
* Crear una identidad sólida y diferenciada de otras escuelas de arquería de la zona, junto con la creación de un logotipo con buena lectura en tamaño pequeño
* Diseñar una página coherente, intuitiva y que permita atraer nuevos alumnos
* Solucionar los problemas de código que presenta la página actualmente
* Adaptar la página para que pueda ser usada en dispositivos móviles
  
## Detalles técnicos
Usamos el editor de código Visual Studio Code y la herramienta Figma para el maquetado y prototipado de la página web. El diseño fue realizado para una resolución de pantalla de 1920x1080
